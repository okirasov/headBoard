# Headboard API Implementation Plan (.NET 10)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A .NET 10 Web API in `apps/api` that persists the Headboard model per user, authenticates with Google/Apple id-tokens, and provides AI task extraction and digest generation through the Anthropic API.

**Architecture:** Minimal APIs grouped by feature (Auth, Tasks, Projects, Files, Comments, Settings, Ai). EF Core with SQLite in development and PostgreSQL when a `Postgres` connection string is present. JWT bearer auth; every entity row is scoped by `UserId`. DTOs use camelCase and epoch milliseconds so they match `packages/core/src/model.ts` exactly.

**Tech Stack:** .NET 10 (`dotnet --version` = 10.0.103), Microsoft.EntityFrameworkCore.Sqlite, Npgsql.EntityFrameworkCore.PostgreSQL, Microsoft.AspNetCore.Authentication.JwtBearer, Google.Apis.Auth (Google id-token validation), Microsoft.IdentityModel.Protocols.OpenIdConnect (Apple JWKS), xunit + Microsoft.AspNetCore.Mvc.Testing.

**Spec:** `docs/superpowers/specs/2026-09-08-headboard-implementation-design.md` §API and §Data model; prompts live in `packages/core/src/capture.ts` (`extractPrompt`) and `packages/core/src/digest.ts` (`digestPrompt`) and must be reproduced verbatim in C#.

## Global Constraints
- Solution: `apps/api/Headboard.Api.sln` with projects `Headboard.Api` and `Headboard.Api.Tests`.
- Wire format = core TS model: `Task {id, title, proj, pr(0|1|2), status('inbox'|'focus'|'waiting'|'done'|'archived'), touched, created, due|null, snoozedUntil, recur('weekly'|null), tags[], note, chat|null, files[], comments[], doneAt|null}`, `FileRef {id,name,kind('img'|'file'),size?,src?}`, `Comment {id,text,at}`, `Project {id,name,color}`, `User {name,email,provider('Google'|'Apple'),initials}`. Timestamps are epoch ms (`long`).
- Config keys: `Jwt:Secret`, `Jwt:Issuer`, `Auth:GoogleClientId`, `Auth:AppleClientId`, `Auth:AllowDevLogin` (bool, default true in Development), `Anthropic:ApiKey`, `Anthropic:Model` (default `claude-sonnet-5`), `ConnectionStrings:Postgres` (optional), `Storage:Root` (default `./storage`).
- CORS: allow `http://localhost:5173` and `http://localhost:8081` (Expo) in Development.
- Listen on `http://localhost:5080`.
- No demo data. `dotnet build` must have zero warnings-as-errors failures; `dotnet test` green.

### Task 2: Auth (Google/Apple id-token → JWT, dev login)
**Files:** `Auth/AuthEndpoints.cs`, `Auth/TokenService.cs`, `Auth/GoogleVerifier.cs`, `Auth/AppleVerifier.cs`, `Auth/CurrentUser.cs`.
**Produces:** `POST /auth/google {idToken}` and `POST /auth/apple {idToken}` → `{token, user:{name,email,provider,initials}}`; `POST /auth/dev {email,name,provider}` (only when `Auth:AllowDevLogin`); `GET /me` → user. `CurrentUser.Id(HttpContext)` reads the `sub` claim.
- [ ] Test (`Headboard.Api.Tests/AuthTests.cs`): dev login returns token; `GET /me` with token returns the user; without token → 401.
- [ ] Implement: on first login upsert `UserRow` by (provider, subject); `initials` = first letters of up to two name words.
- [ ] Tests pass. Commit `feat(api): auth`.

### Task 3: Tasks, comments, projects, settings
**Files:** `Tasks/TaskEndpoints.cs`, `Tasks/TaskDto.cs`, `Tasks/TaskMapper.cs`, `Projects/ProjectEndpoints.cs`, `Settings/SettingsEndpoints.cs`.
**Produces:** `GET /tasks` (all non-archived + archived flag via `?includeArchived=true`), `POST /tasks` (body = Task, server assigns id if empty), `PATCH /tasks/{id}` (partial Task), `DELETE /tasks/{id}`; `POST /tasks/{id}/comments {text}` → Comment; `DELETE /tasks/{id}/comments/{cid}`; `GET/POST/PATCH/DELETE /projects`; `GET /settings` and `PUT /settings {lang,theme,showDone,digestText}`.
- [ ] Test (`TasksTests.cs`): create → list → patch status to done sets `doneAt` when body has it → comment → delete; cross-user isolation (second dev user sees nothing).
- [ ] Implement mapper Task⇄TaskRow (tags as JSON array). All queries filter by `UserId`.
- [ ] Tests pass. Commit `feat(api): tasks, projects, settings`.

### Task 5: AI endpoints (Anthropic)
**Files:** `Ai/AiEndpoints.cs`, `Ai/AnthropicClient.cs`, `Ai/Prompts.cs`.
**Produces:** `POST /ai/extract {text, projects:[{id,name}]}` → `CaptureItem[]` `{title, pr, tags, proj}`; `POST /ai/digest {stats:{dueN,dueFirst,staleN,oldT,oldI,doneW,focusN,recN}, lang}` → `{text}`. Without `Anthropic:ApiKey` → `503 {error:"ai_unavailable"}` so clients fall back locally.
- [ ] `AnthropicClient`: `POST https://api.anthropic.com/v1/messages` headers `x-api-key`, `anthropic-version: 2023-06-01`, body `{model, max_tokens: 800, messages:[{role:'user', content}]}`; return concatenated text blocks.
- [ ] `Prompts.Extract(text, projectNames)` and `Prompts.Digest(stats, lang)` reproduce the TS prompts verbatim. Extract response parsing: slice from first `[` to last `]`, JSON parse, clamp priority 0..2, tags ≤ 2, project name → id or null, drop empty titles.
- [ ] Test: without key → 503; with a fake `HttpMessageHandler` returning `[{"title":"Do it","priority":2,"tags":["a","b","c"],"project":"Home Ops"}]` → one item `{pr:2, tags:[a,b], proj:"p4"}`.
- [ ] Commit `feat(api): ai extract and digest`.

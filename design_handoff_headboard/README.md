# Handoff: Headboard — personal thinking board (Web + iOS)

## Overview
Headboard — персональная канбан-доска «разгрузки головы»: пользователь сбрасывает сырой текст (чат с Claude, заметки, braindump), приложение превращает его в задачи и раскладывает по трём колонкам (Inbox / In focus / Waiting on). Есть ревью «пыльных» задач, календарь с нагрузкой по дням, комментарии и вложения, утренний дайджест, вход через Google/Apple, светлая и тёмная темы, локализация RU/EN.

## About the Design Files
Файлы в пакете — **дизайн-референсы, собранные в HTML** (прототип, показывающий вид и поведение). Это НЕ production-код. Задача разработки — **воссоздать эти экраны в целевом стеке** (React/Vue/SwiftUI/native — по существующим паттернам кодовой базы; если кодовой базы нет — выбрать подходящий фреймворк, например React + Tailwind для web и SwiftUI для iOS). `Headboard.dc.html` открывается в браузере (рядом должны лежать `support.js` и `ios-frame.jsx`) и показывает оба вьюпорта на одном холсте: Web 1440×900 и iOS 402×874.

## Fidelity
**High-fidelity.** Цвета, типографика, отступы, радиусы, состояния — финальные; воспроизводить пиксель-в-пиксель токенами ниже. Демо-данные (задачи, проекты, файлы) — образцы контента, не хардкодить.

## Typography
Стек проекта Teach (Google Fonts, кириллица везде):
- **Golos Text** — весь UI и заголовки. h1 экранов (Доска/Разбор/Дайджест/Календарь, мобильный титул) 26px/500, letter-spacing −.3px, line-height 1.2; заголовки шторок/drawer/модалок 18–22px/500; заголовки карточек 14–14.5px/500/1.4; кнопки и нав-пункты 500–600 13–13.5px; основной текст 13px/1.55.
- **IBM Plex Mono** — метки, даты, чипы, счётчики: 9–11px, кикеры uppercase с letter-spacing .08–.1em.
- Серифы из UI убраны полностью; жирный вес 600+ используется только в чипах-счётчиках и кнопках.

## Logo
Локап: знак «мысль-доска» + wordmark «board» (строчными), выровнены по вертикальному центру, зазор 6–8px.

**Знак** (viewBox 0 0 48 48): голова `circle cx=15 cy=38 r=7.5` fill --ink; пузырёк `circle cx=24 cy=29 r=2.6` fill --ink; тайл-доска `rect x=25 y=3 w=19 h=19 rx=7 stroke=--ink stroke-width=5 fill=none`; задача в углу тайла: подложка `circle cx=40.5 cy=18.5 r=4.4 fill=<локальный фон: --panel или --bg>` + `circle r=3.1 fill=--acc`. Размеры: титул 34px, сайдбар 25px, экраны входа 32px, iOS-хедер 20px.

**Wordmark**: текст «board» — Golos Text **400**, letter-spacing −.3px, буква «o» цветом --acc. Размеры: сайдбар 21px, iOS-хедер 20px, экраны входа 26px, титул 28px. Никаких рисованных букв и жирных весов.

Иконка приложения: знак на --panel (light) либо на #C8552F с кремовой заливкой #FFF3EC.

## Interactions & Behavior
- DnD карточек между колонками (HTML5 draggable; на iOS — через смену статуса в тикете).
- Приоритеты: 3 уровня (0 High / 1 Medium / 2 Low), меняются кружками в тикете; на карточке — только цветовая полоса, без текста.
- Snooze: календарь-пикер (fadeUp), пресеты; snoozed-задача получает бейдж и «спит» до даты.
- Capture: текст → задачи. Приоритет эвристикой (urgent/asap/срочно → High, иначе Medium), теги из #хештегов, проект по ключевым словам; если доступен `window.claude.complete` — парсинг через Claude (JSON: title, proj, priority 0|1|2, tags).
- Дайджест: генерируется по текущим задачам (текст в сайдбаре), кнопка обновления.
- Вложения: file input (multiple), картинки читаются в dataURL и показываются в превью; чужие форматы — карточка «нет предпросмотра». Удаление — крестик на чипе (stopPropagation).
- Комментарии: Enter добавляет, время «только что/сегодня/дата».
- Темы: system-default → пользовательский выбор в профиле; язык RU/EN — полный словарь строк (см. объекты `EN`/`RU` в логике прототипа).
- Persist: localStorage-ключ `oboard-v3` {tasks, digestText, lang, projFiles, user, theme}.
- Вход: Google/Apple (мок) — до входа весь UI закрыт экраном sign-in; выход возвращает на него.

## State Management
`tasks[]` {id, title, proj, pr 0|1|2, status inbox|focus|waiting|done, touched, created, due?, snoozedUntil?, recur?, tags[], note?, chat?, files[], comments[], doneAt?}; `projects[]` {id, name, color}; `projFiles{}`; `user` {name, email, provider, initials} | null; `lang`, `theme`; UI-стейт: выбранная задача (drawer/sheet), фильтры (проект, приоритет, поиск), capture, snooze-пикер, файловые превью (web `pv` и mobile `mPv` — раздельные), профиль-меню.

## Assets
Внешних ассетов нет: логотип — inline SVG (спека выше), иконки — простые inline SVG-штрихи (стрелки, крестики, чек). Шрифты — Google Fonts (Literata, Newsreader, Instrument Sans, Spline Sans Mono). Демо-вложения — заглушки без бинарников.

## Files

## Migration note
Прототип мигрирует сохранённые данные: при загрузке localStorage-ключа `oboard-v3` строки «oBoard/Offload» в заголовках, заметках и дайджесте заменяются на «Headboard» — переносить эту логику в прод не нужно, это артефакт истории прототипа.
